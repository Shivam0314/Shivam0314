## 📌 Featured Project

### 🎟️ [Event Booking & Order Management System](https://github.com/Shivam0314/event-booking-system)

> A production-like full-stack microservices-based booking platform inspired by enterprise systems like Disney's reservation platform.

**Tech:** Java 17 · Spring Boot 3.2 · React 18 · MySQL · Docker · Grafana Loki · iText7

| Feature | Details |
|---|---|
| Architecture | 7 Spring Boot microservices + Netflix Eureka + Spring Cloud Gateway |
| Payment | Mock gateway with FULL / PARTIAL / BALANCE payment flows |
| PDF Tickets | iText7-generated tickets with passenger manifest |
| Email | Gmail SMTP with PDF attachment via async processing |
| Logging | Grafana Loki + Promtail + pre-built dashboards |
| API Docs | Swagger UI on all 7 services |
| DevOps | Docker Compose + GitHub Actions CI/CD |
